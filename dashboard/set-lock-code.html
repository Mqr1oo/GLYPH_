Cod de acces GLYPH

Scrie codul pe care vrei să-l ceară aplicația. Pagina asta îl transformă în trei valori pe care le lipești în glyph.html. Codul în sine nu pleacă nicăieri — calculul se face aici, în browser. 


    
    

      Înlocuiește blocul const GLYPH_LOCK = {...} din
      glyph.html cu textul de mai sus.


      Ține minte codul. Nu poate fi recuperat din
      valorile astea — asta e tot rostul lor. Dacă îl uiți, generezi altul.
